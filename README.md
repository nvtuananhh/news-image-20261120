in Poland, the UK–EU reset deal, and 23 more briefs plus sport — 36 stories in all.

## How it works

- `poster.png` is rendered at build time by `gen_poster.py` (Pillow, build-time only).
- `main.py` is standard library only (`os`, `shutil`, `sys`): it copies `poster.png`
  to `$MAKEFUN_OUTPUT_DIR/entry.png`. It runs clean under `python3 -P -s` with no
  network, and two runs write byte-identical files.
